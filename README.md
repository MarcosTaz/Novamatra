# NOVAMATRA

Independent research and engineering platform based in Leiria, Portugal.

This repository contains the NOVAMATRA institutional website (Portuguese and English), with independent pages for energy systems, smart footwear, emergency systems, strength exoskeletons, medical mobility research, research methods, collaboration and current evidence.

## Publishing

Static HTML/CSS/JS. Publish root `./` on Render Static Site. Root redirects to `/pt/`. English begins at `/en/`. `robots.txt` and `sitemap.xml` are included.

**Research-stage disclosure:** Visuals are conceptual; physical performance and partnerships must not be represented as validated without evidence.
