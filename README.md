# NOVAMATRA

Independent research and engineering initiative based in Leiria, Portugal.

## Public website

The public presence at www.novamatra.com is a **single institutional presentation page** in Portuguese, English and French, with no publication of research sectors, project catalogues, prototypes or study details.

- Entry: `index.html` (standalone HTML/CSS/JS, no external dependencies)
- Former public project/section routes redirect to the entry page.
- Sitemap contains only the root URL.

## Protected platform

`private-platform/` is separate application code and is **not changed** by the public-site landing revision. Neither the landing page nor this public repository is an access control mechanism. Do not place confidential project code, credentials or partner material in the public website or repository.
